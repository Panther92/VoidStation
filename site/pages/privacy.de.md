## Hosting bei GitHub Pages {#hosting}

Diese Webseite wird über GitHub Pages ausgeliefert, einen Dienst von GitHub (ein Unternehmen von Microsoft). Wenn du eine Seite aufrufst, verarbeitet GitHub dabei technisch notwendige Daten – insbesondere deine IP-Adresse, Datum und Uhrzeit, die aufgerufene Adresse und die Kennung deines Browsers. GitHub nutzt diese Daten, um die Seite auszuliefern und sie vor Angriffen zu schützen; sie können auch in den USA verarbeitet werden.

Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO: das berechtigte Interesse an einer sicheren und zuverlässigen Bereitstellung der Seite. Auf diese Protokolle habe ich selbst keinen Zugriff, und ich führe keine Besucherstatistik. Einzelheiten stehen in der [Datenschutzerklärung von GitHub](https://docs.github.com/de/site-policy/privacy-policies/github-general-privacy-statement).

Diese Seite setzt keine Cookies, speichert nichts in deinem Browser und bindet keine Inhalte anderer Anbieter ein – auch die Schrift wird von hier geladen, nicht von Google. Das kleine Skript der Seite (Uhr, Filter, Kopieren) läuft nur in deinem Browser und sendet nichts.
